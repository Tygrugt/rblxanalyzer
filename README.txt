# rblxanalyzer 🎮📊

**rblxanalyzer** is a Python application with a GUI for analyzing and storing information about Roblox games. It allows you to collect data about games, analyze player activity, and visualize statistics.

## 🧩 Features

- 📚 Save games to a list with the ability to easily load
- 📄 Save basic game data (name, description, etc.)
- 🖼️ Save game icons and screenshots
- 📊 Analytics: visits, active players, likes, dislikes, favorites and rating
- ⚠️ Warning: there may be frequent freezes during use

## 🚀 Installation

1. Make sure you have Python 3.10+ installed
2. Install dependencies:
    matplotlib==3.10.1
    Pillow==11.2.1
    requests==2.32.3
